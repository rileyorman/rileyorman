# Riley Orman

I spent fifteen years selling to Alberta energy companies, co-founded a working-capital lender, and now I build finance tools with Python and Claude. Calgary, MBA.

## What I have built

**[FinLens](https://github.com/rileyorman/finlens).** An investment-analysis app for Canadian mining and resource companies. It pulls the fundamentals from SEDAR filings, cross-checks them with Claude models tiered by task, and keeps an integrity log so every figure has a source. The analysis follows value-investing rules: margin of safety, intrinsic value, downside risk. The code, the test suite and the design record are in the repository.

**SAIT Vendor Workbench.** A Python and Streamlit application built for SAIT Commercial Services to administer campus vendor rent: monthly sales and rent entry, corrections with an audit trail, lease renewals with maker-checker confirmation, and a one-click month-end pack for the CFO meeting. About 1,100 automated checks prove every on-screen figure matches the client's records to the cent. Built under a confidentiality agreement, so the code stays with SAIT.

**Fieldline Receivables.** The operations platform for a receivables-finance business I am building for energy-services suppliers: invoice purchase, buyer-led programs, settlement, audit trail and investor reporting. Private.

I build with Claude Code and gate every change with tests and a scripted walkthrough before it ships. The finance comes first; the code exists to make a number I trust.
